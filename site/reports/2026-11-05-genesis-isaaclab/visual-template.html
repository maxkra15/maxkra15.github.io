Methods & downloads Data, source and reproducibility

What was measured

ANYmal-C velocity tracking, Cartpole balance and fixed-base Franka reaching. Both backends use the same prepared robot inputs, controls, task code and PPO implementation.

Rollouts include simulation and task updates; RGB adds native rendering. Startup uses the selected rollout workload. PPO time is the full fixed-budget cost, including evaluation.

What to keep in mind

Genesis uses Newton with a 25-iteration maximum and native tolerance. MJWarp uses Newton, implicitfast, 100 solver / 50 line-search iterations, tolerance 1e-6 and one substep. These settings do not establish equal physical accuracy.

Each task pairs both backends on the same physical L40. The baseline and Franka cohorts overlapped on separate GPUs on the same host. Three seeds show an observed range, not a confidence interval.
